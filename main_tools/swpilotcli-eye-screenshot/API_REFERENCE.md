# EyeScreenshot API Reference

## Arguments

None.

## Output File

`./temp/screenshot/screenshot.png`

Path is relative to the SwpilotCLI project root (located by finding `CLAUDE.md` or `AGENTS.md` in parent directories).

## Return Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Unhandled exception |
