# swpilotcli-inspect-sketch-setup

Inspect the currently edited sketch and print its points, segments, and feature context.

## Quick start

```bash
dotnet run --project ./sup_tools/swpilotcli-inspect-sketch-setup/scripts/InspectSketchSetup/InspectSketchSetup.csproj
```
